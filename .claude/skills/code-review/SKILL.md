# Процесс ревью
1. Найди все изменённые файлы (git diff)
2. Проверь:
   - Используются ли параметризованные запросы?
   - Нет ли закомментированного кода?
   - Есть ли обработка исключений?
   - Следует ли код PEP8?
3. Верни отчёт в формате:
   - Плюсы
   - Минусы (с указанием строк)
   - Рекомендации
